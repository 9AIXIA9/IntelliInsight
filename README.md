# 项目概述 - IntelliInsight 爬虫分析系统

## 项目架构

本项目是一个分布式爬虫与数据分析系统，采用微服务架构：

- **前端/分析平台**：Python FastAPI 服务
- **爬虫核心**：Go 服务
- **通信方式**：gRPC
- **数据存储**：MongoDB

## 技术栈

- **Python 端**：
	- FastAPI 框架
	- Motor (异步 MongoDB 驱动)
	- gRPC 客户端
	- Pydantic 数据验证
	- Uvicorn 服务器

- **Go 端**：
	- 高性能爬虫核心
	- gRPC 服务端

## 主要功能

1. 创建爬虫任务：指定关键词、页数、类别等参数
2. 查询爬虫状态：实时监控爬虫进度
3. 获取爬取数据：分页查询、过滤结果

## 系统特点

- 高性能：Go 实现的爬虫核心
- 易用性：Python FastAPI 提供友好的 REST API 和 Swagger 文档
- 可扩展：微服务架构便于横向扩展
- 异步操作：全链路异步支持高并发请求

该系统旨在提供高效、可靠的数据采集和分析能力，支持大规模网络内容的爬取和处理。
